# 第三章 存储系统

## 📌 本章框架
- 存储器分类与性能指标
- 存储器层次结构
- 主存
- Cache
- 虚拟存储器
- 多模块存储器

## ✅ 核心考点
### 1. 存储器性能指标
- 存储容量：存储单元个数 × 字长
- 存取时间：从发起读请求到数据读出的时间
- 存取周期：连续两次访问存储器的最小间隔（存取周期 ≥ 存取时间）
- 带宽：单位时间内存取的数据量

> 区分：存取时间是一次读操作的耗时；存取周期包含读出+恢复，所以一定更大。

### 2. 存储层次
速度排序：寄存器 > Cache > 主存 > 辅存
容量排序：寄存器 < Cache < 主存 < 辅存
单位成本：寄存器 > Cache > 主存 > 辅存

层次思想：用Cache弥补CPU和主存的速度差；虚拟存储弥补主存容量不足。

### 3. Cache
- 命中率 $H$：访问Cache命中次数 / 总访问次数
- 平均访问时间：
$$T_a = H \cdot T_c + (1-H)\cdot T_m$$
$T_c$：Cache访问时间，$T_m$：主存访问时间

- 三种映射方式
  - 直接映射：主存块号 mod Cache块数，冲突高，硬件简单
  - 全相联：块可以放到任意Cache位置，冲突最低，硬件贵
  - 组相联：先分组，组内全相联、组间直接映射（考试最常考）
- 替换算法：FIFO（先进先出）、LRU（最近最少使用，重点）
- 写策略
  - 写直达：同时写Cache+主存，一致性好，速度慢
  - 写回：只写Cache，淘汰时才回写主存，速度快，需要修改位

### 4. 虚拟存储器
- 分类：页式、段式、段页式
  - 页式：页大小固定，分配简单，有内碎片
  - 段式：段长可变，按逻辑模块划分，有外碎片
  - 段页式：先分段、再分页，结合两者优点，地址变换复杂
- 概念：逻辑地址（虚地址）、物理地址（实地址）、页表、TLB快表
- TLB：存放常用页表项，加速地址转换，属于Cache的一种

### 5. 多模块存储器
- 单体多字：一次读出多个字，适合连续访问
- 多体并行（交叉编址）：M个存储体轮流访问，流水线，适合连续读取

## ❗易混点
1. 存取时间 ≠ 存取周期
2. LRU：淘汰**最近最少被访问**的，不是最先进入的，和FIFO不一样
3. 组相联：Cache块先分组，组内全相联、组间直接映射
4. TLB是快表，存页表项；Cache存指令/数据，二者不是一回事

## 📝 典型例题
> 例：Cache访问时间10ns，主存访问60ns，命中率90%，求平均访问时间
$T_a = 0.9\times10 + 0.1\times60 = 15\ \text{ns}$

存储体系的核心就是**速度、容量、价格三者折中**；Cache解决速度，虚拟存储解决容量，组相联+LRU是大题高频考点。
